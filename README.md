### ✍️ About the service
**Help Service** - is a part of the Appeals Project.  
It should help users to navigate in the project.
---
### ⚒️ Tech
- Java 21
- Spring Boot 4.0.0
- Gradle
- Docker

---

---
### 🧩 Start project

``` bash
git clone https://github.com/pepegazxc/HelpService-appealsProject.git
cd HelpService-appealsProject
```

And then run the containers:
``` bash
docker-compose up -d
```
